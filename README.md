# ☯️ GYGS Metaphysical Analytics Engine (gygs.ca)

## Overview
This repository contains the frontend architecture and core logical framework for **gygs.ca**. It is an all-in-one, data-driven metaphysical knowledge base designed to digitize and synchronize three major pillars of traditional Chinese life analysis:
1. **Zi Wei Dou Shu (紫微斗數)** - Micro-level event and psychological profiling.
2. **Bazi / Four Pillars of Destiny (八字算命)** - Macro-level energy, elemental balance, and decadal trends.
3. **Physiognomy (面相學)** - Morphological correlation (Integration in progress).

## 🎯 Core Philosophy: Statistics Over Subjectivity
Unlike traditional fortune-telling platforms that rely on vague, Barnum-effect statements and "imaginary" interpretations, this engine is built strictly on **algorithmic cross-referencing**. 

By inputting precise data (Date of Birth, Accurate Time, Country of Birth/Timezone, and Gender), the system:
* **Back-tests the past:** Validates the algorithm by cross-referencing the calculated chart with the user's historical timelines.
* **Forecasts the future:** Generates specific timeframe predictions based *only* on legitimate, classical texts and statistical pattern matching. 

## 🚀 Features
* **Multi-System Synchronization:** Analyzes the overlap between Zi Wei stars and Bazi elements to filter out contradictions and find high-probability outcomes.
* **Geographical Accuracy:** Accounts for the country of birth to adjust for true solar time and geographic elemental shifts.
* **Zero-Hallucination Parsing:** Prompts and knowledge bases are strictly constrained to established classical rulesets (e.g., *Zi Wei Dou Shu Quan Shu*), ensuring the AI does not invent interpretations.
